## Updating the Website

The website is edited locally and managed using GitHub Desktop.

1. Edit the relevant HTML, CSS or JavaScript file.
2. Test the website locally.
3. Commit the changes using GitHub Desktop.
4. Push the changes to GitHub.
5. GitHub Pages automatically updates the live website.
